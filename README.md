# CMU Datathon · Find the right care

Search for a named service near a location. The notebook logic compares published evidence, ML-assisted field estimates, and interpretable regression estimates. It returns source excerpts, location and contact provenance, and the reasons a facility was selected or held for review.

- [Project summary](non-ml/PROJECT_SUMMARY.md) covers the evidence, decisions, iterations, and submission criteria.
- [Data comparison](non-ml/DATA_COMPARISON.md) shows where the challenge dataset and public sources overlap and what each can substantiate.
- [Mass verification](non-ml/MASS_VERIFICATION.md) covers the pre-launch Hindi calls, review workflow, and cost scenarios.
- [Modular notebooks](non-ml/README.md) cover source audits, location cleanup, model readiness, recommendations, and opt-in load balancing.
- [Existing modeling work](ML/) contains the capacity random forest and earlier modeling notebooks.
- [Public-source data](data/) and the [action log](ACTION_LOG.md) document collection and verification.
